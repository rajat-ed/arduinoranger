# Time (s) Displacement (cm) Velocity (cm/s) Acceleration (cm/s²)
No data yet — press Record and start moving!
📏
Displacement
s = dmeasured
How far the object is from the sensor. The HC-SR04 sends a sound pulse and measures how long the echo takes to return. Distance = (speed of sound × time) ÷ 2.
⚡
Velocity
v = Δs ÷ Δt
How quickly the displacement is changing. Positive means moving away from the sensor; negative means moving closer. Units: cm/s.
🚀
Acceleration
a = Δv ÷ Δt
How quickly the velocity is changing. This is the second derivative of position. During free-fall, a ≈ 980 cm/s² downward.
🏀 Bouncing BallDrop a ball above the sensor. See parabolic displacement + near-constant acceleration during free-fall.
🌊 Spring OscillationHang a mass on a spring. Displacement and velocity will be sine waves 90° apart.
🚗 Cart on RampPush a cart down a slope. Observe constant positive acceleration and increasing velocity.
👋 Hand WavingWave your hand back and forth. All three graphs update in real time — great for building intuition!
⚠️ Wire the sensor: TRIG → Pin 5  |  ECHO → Pin 6  |  VCC → 5V  |  GND → GND
// Motion Lab — HC-SR04 Ultrasonic Sensor // TRIG → Pin 5 | ECHO → Pin 6 // Upload this sketch, then connect in the app. #define TRIG_PIN 5 #define ECHO_PIN 6 const int INTERVAL_MS = 200; // 5 Hz — change to match app setting unsigned long lastTime = 0; void setup() { Serial.begin(9600); pinMode(TRIG_PIN, OUTPUT); pinMode(ECHO_PIN, INPUT); } void loop() { unsigned long now = millis(); if (now - lastTime >= INTERVAL_MS) { lastTime = now; // 1. Fire a 10µs pulse on TRIG digitalWrite(TRIG_PIN, LOW); delayMicroseconds(2); digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10); digitalWrite(TRIG_PIN, LOW); // 2. Measure echo duration (max 30ms timeout) long duration = pulseIn(ECHO_PIN, HIGH, 30000); // 3. Convert to cm and send over Serial if (duration > 0) { float cm = (duration * 0.0343) / 2.0; if (cm >= 2 && cm <= 400) { Serial.println(cm, 2); } } } }
